# MyTaskDesk

MyTaskDesk is a desktop task and expense management application built with **Python, Tkinter, and SQLite**.

It was developed as a final-year Software Engineering project to provide users with a simple application for organizing tasks, managing deadlines, and tracking daily expenses.

## Features

- User registration and login
- Task creation and management
- Task categories and priorities
- Task status tracking
- Due dates and times
- Task reminders
- Task filtering and sorting
- Expense tracking
- Expense category management
- Local SQLite database storage
- Input validation

## Technologies Used

- **Python**
- **Tkinter**
- **SQLite**
- **Tkcalendar**

## Project Purpose

MyTaskDesk was developed as a final-year Software Engineering project to provide users with a simple desktop application for managing personal tasks and daily expenses.

The project provided practical experience in GUI development, database management, user authentication, input validation, and application logic using Python.

## Installation

1. Clone the repository:

```bash
git clone https://github.com/eugeneekong08-hash/MyTaskDesk.git
```

2. Open the project folder:

```bash
cd MyTaskDesk
```

3. Install the required Python package:

```bash
pip install tkcalendar
```

## Running the Application

Run the main Python file:

```bash
python mytaskdesk.py
```

The application will create and use a local SQLite database for storing users, tasks, and expenses.

## Platform Note

The task reminder sound uses Python's `winsound` module, so the current reminder implementation is designed for **Windows**.
